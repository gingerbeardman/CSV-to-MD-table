# CSV to MD table

CSV to MD table is an extension for the [Nova editor](https://nova.app).

It converts tabular data between CSV/TSV and Markdown formats, in either direction.

See the internal [README](/CSV%20to%20MD%20table.novaextension/README.md) for more info.

Recommended download from [Nova Extensions](https://extensions.panic.com/extensions/com.gingerbeardman/com.gingerbeardman.csv2md/) website.
